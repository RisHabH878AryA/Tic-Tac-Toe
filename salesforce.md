# what is salesforce?
It is a cloud based CRM which is used to store or manage the customer data.
It was founded by Mr Marc benioff in 1990.

## In Excel:
-> table stands for the object. </br>
-> column stands for the field. </br>
-> Data stands for the record. </br>

## Steps to create the object or table:
1. Click on gear icon > setup > object manager > create > custom object
2. Name the labels and check the last two checkboxes > Save
3. Select a tab style > next next > save

## Steps to create the columns or fields:
1. go the the created object > Field and relationships.
2. Click on the new button > select the data type > next .. > save.

## How to create the data?
1. Click on the app launcher (nine dots)
2. Type the object name
3. To add records/data click on the new button

## DIFF between standard and custom object in salesforce.
   1. Standard object: created by salesforce.</br>Custom object: created by the developer or the customer based on their usecase.
   2. Standard object: no __C </br>Custom object: __C is present.
   3. Standard object: We can't delete.</br>Custom Object: We can delete.
